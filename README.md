# Canti

Prima versione PWA per archivio personale di canti.

## Include
- Importazione di file `.crd` e `.txt`
- Inserimento manuale di canti
- Ricerca per titolo
- Lettura con carattere regolabile
- Trasposizione semplice degli accordi
- Memorizzazione locale sul dispositivo
- Supporto base per installazione PWA e uso offline

## Limiti di questa versione
- I PDF non sono ancora archiviati/visualizzati.
- Google Drive non è ancora collegato: i canti restano salvati nel browser/dispositivo.
- La trasposizione riconosce gli accordi più comuni; controllare il risultato per notazioni particolari.

## Pubblicazione
Caricare tutti i file nella cartella principale del repository GitHub e abilitare GitHub Pages dalle impostazioni, scegliendo il branch `main` e la cartella `/(root)`.
